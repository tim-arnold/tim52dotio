## Contributing Guidelines

When creating new guides:

1. **Focus on practical examples**: Include code snippets and real-world scenarios
2. **Keep it current**: Update guides as patterns evolve
3. **Include rationale**: Explain why certain approaches are recommended
4. **Cross-reference**: Link to related guides and documentation
5. **Test examples**: Ensure all code examples work with current codebase
